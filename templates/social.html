Before enabling

  1. Set the venue’s tables, capacities, service sessions, sitting duration, turnaround time, booking limits and deposit rules in Bookings.
  2. Complete Meta app configuration, privacy/data-deletion requirements and webhook subscriptions for both Page and Instagram messages.
  3. Install the database booking guard and start the background worker described in the installation guide.
  4. Complete live acceptance testing before using the assistant with customers.
Live Meta messaging is not yet verified. The assistant supports UK-time reservations, guided date/time entry and one table per booking. It hands deposits, large parties, special requests, changes, cancellations, attachments and unclear enquiries to staff. Alternative slots are offered on the same date or the following three days and are not held.

Messages are processed only for Active subscriptions. Demo preview can open this page but does not bypass that worker restriction. The assistant replies within the standard 24-hour incoming-message window. It does not send marketing, reminders or unsolicited messages.

Privacy and account access

Only reservation messages received after automation is enabled are processed. Connection tokens, message text and conversation details are encrypted in Alport’s database. Confirmed guest and booking records use the existing booking storage. You must update your public privacy notice to explain this processing and configure retention before launch. Do not ask guests to send card details or sensitive medical information.

Disconnecting removes Alport’s stored access token and pauses local processing. Also remove the app in Meta’s business integrations if you want to revoke the provider authorisation.
